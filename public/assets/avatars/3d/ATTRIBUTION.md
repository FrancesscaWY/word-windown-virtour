# Fox sample model

`Fox.glb` is the unmodified Fox model distributed by the Khronos glTF
Sample Assets project and used by Three.js official animation examples.

Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox

Downloaded 2026-11-10 from:
https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/Fox/glTF-Binary/Fox.glb

- Model: PixelMannen, 2014, Creative Commons Zero v1.0 Universal (CC0).
  https://creativecommons.org/publicdomain/zero/1.0/legalcode
- Rigging and animation: tomkranis, 2014, Creative Commons Attribution
  4.0 International (CC BY 4.0).
  https://creativecommons.org/licenses/by/4.0/legalcode
- glTF conversion: @AsoboStudio and @scurest, 2017, Creative Commons
  Attribution 4.0 International (CC BY 4.0).
  https://creativecommons.org/licenses/by/4.0/legalcode

This project changes only display lighting, scale, camera framing, and
animation playback. The model file is unchanged. Survey, Walk, and Run
are the original skeletal animation clips. There are no facial expression
or speech viseme clips in this model.

The accompanying `GLTFLoader.js` and `BufferGeometryUtils.js` are from
Three.js r170, MIT license. See `src/vendor/THREE-LICENSE.txt`.

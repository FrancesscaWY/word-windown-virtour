# 入口页面素材

全部来自用户提供的 `public/design/介绍页.zip` 与 `public/design/yindao.png`。

欢迎页沿用原始竖排标题、动物导游、水彩建筑与左滑提示。引导页插画从参考图裁切，文字与点击区域使用原生 HTML；纸张纹理由参考图无文字区域镜像拼接。未改动原始附件，未引入远程图片或新生成形象。

建筑与三张模式插画按各自纸张底色生成柔和的颜料透明蒙版，并对裁切边缘羽化，消除原先浅色矩形的接缝。欢迎页底层晕染单独截取无建筑的区域，避免重复建筑；纸纹降低橙色强度，使角色、建筑和 UI 使用统一的奶油色底。

左上枝叶也去除原截图的纸底，保留枝叶颜料与透明边缘。标题另外裁出“世界之旅”（117×534）与“AI 伴游”（134×384）两列，沿用原字形，独立排布；原始整张标题继续保留。

使用 `python scripts/prepare-arrival-assets.py` 重建，需要 Pillow。`manifest.json` 记录派生素材的 SHA-256。

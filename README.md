# VirTour · 世界之窗导览

面向游客的移动端单页 Demo：真实 OSM 地理底图、景点搜索、园区实拍、数字人语音陪游、兴趣推荐与字幕联动。前端保持原生 ESM / CSS / WebGL，后端为 Fastify 5 + TypeScript，直接运行模型调用、工具和本地知识库。

## 当前覆盖（2026-11-09）

- 106 条有来源的景点及体验记录，44 处有 OSM 园内坐标。其余条目可搜索、可语音询问，位置未核对时不在地图上猜放标记。
- 已修复旧下载范围裁切西侧、北侧园界的问题。首页完整显示园界，支持“看全园”、拖动和缩放；地图使用轻量的建筑插画标记，底部统一显示来源署名。
- 新增设施入口：1 处 OSM 卫生间、2 处通行待核实的园界门，以及前广场票务中心和国际街商业服务区的来源说明。无坐标服务点不放地图标记，不把园界门当作已确认出口。
- 数字导游保留原有 10 个版本，增加直接保留设计图纹理的「沐沐 · 水彩」和「绒绒 · 毛毡」，共 12 项可切换。新版本支持拖动、表情、行走、招手、指景及播放状态驱动口型。
- 10 张园区实拍照片覆盖 12 个地点，包含两组同框照片；照片画面保留作者与许可链接，拍摄记录可查看来源。普通照片按原比例显示。
- 当前真实园区 360° 全景为 **0**。按演示需求，铁塔入口恢复原有原创 360° 示例插画，支持拖动、缩放和加载后讲解；保留原有园区照片素材。其他景点继续展示各自实拍或资料。
- 106 条记录包括百科历史清单，**不是官方全量在营名录**。中国旅游集团介绍的规模为 130 多处景观，当前官方完整名录及逐景点全景仍待取得。
- 不提供虚构的距离、人流或排队数值。问“它远不远”会沿用当前话题，说明定位缺口并提供景点资料或实拍入口。

逐项覆盖见 [ASSET_COVERAGE.md](ASSET_COVERAGE.md)，来源与许可见 [ASSET_SOURCES.md](ASSET_SOURCES.md)。

页面只设欢迎、模式引导、地图首页、景点画面四类。文字模式采用可拖动的 4:6 画面／对话分栏；伴游也显示数字形象，切后台不主动停止当前讲解。具体布局、后台播放边界及浏览器验证见 [MODE_LAYOUTS.md](MODE_LAYOUTS.md)。

## 启动和手机测试

### 2D / 3D 角色对照 Demo

底部使用两行紧凑控制栏：上行为导游状态与语音/文字入口，下行为导游菜单、表情、动作和自动游走。页头、立体地图、控制栏与对话区域统一使用浅绿和奶油色。默认「沐沐 · 水彩」，菜单保留全部十二项版本，沐沐 · 水彩与绒绒 · 毛毡排在前两位。菜单向上展开，支持滚动、方向键选择、Home / End 跳转及 Escape 关闭。表情始终保留自动、自然、开心、好奇、关切；原创角色支持全部选项，官方示例未提供的表情显示为不可选并说明原因。切换会同步姓名、头像、语音输入提示及无障碍标签。

新增的两个原画版本以还原参考图为优先：

- **沐沐 · 水彩原画／原画骨骼**：直接从 `public/design/digit-hum-1.jpg` 提取透明原画，拆出头、手、双足、围巾和尾巴，以 Canvas 2D 局部关节动画保留原水彩笔触。属于自有分层动画播放器，未引入 Spine 商业运行时。
- **绒绒 · 毛毡原画／预渲染**：保留 `public/design/digit-hum-2.png` 的羊毛纤维、针织围巾、地标和相机，离线烘焙为本地透明 PNG 动画图集，浏览器只选帧与叠加表情。这是原画二维烘焙，并非 Blender 模型渲染；没有背面或自由转身。

两个版本作为独立选项加入，不替换此前 SVG／Three.js 版本。它们只展示实际制作的自然、行走、招手、指景动作；正面双足保持各自的横向通道，小幅交替提足，避免用平面旋转造成交叉。语音实际播放时才切换嘴型，不宣称音素对齐。资源来源、处理方法及重建命令见 `public/assets/reference-avatars/ATTRIBUTION.md`。

此前的沐沐／绒绒 2D、3D 选项仍保留：它们根据 `public/design/digit-hum-1.jpg` 和 `digit-hum-2.png` 用本地 SVG 与 Three.js 重建。沐沐保留探险帽、护目镜、绿色围巾、奶油外套、棕色挎包与水獭尾巴；绒绒保留蒲公英绒环、世界地标头饰、金黄围巾、相机与地球徽章包。2D 使用独立关节和表情层；3D 使用实体几何结构，支持转身和侧背面。它们是参考形象的程序化重建，不是图片自动生成模型或影视级毛发模拟；原始参考图保留不变。

原创角色保留自然、行走、招手、指景、转向动作和表情参数；原创 2D 是 SVG 骨骼演示，转向使用平面翻转。Wanko 只展示它实际提供的 Idle / TapBody 动作；官方 Fox 只展示 glTF 原生 Survey / Walk / Run 和根节点转向。官方 Fox 没有表情和口型同步，Wanko 的口型参数只在真实 TTS 播放时驱动。「自动游走」（原「随行」）只控制画面边缘移动、随所选景点调整停靠位置，不追踪游客真实位置；拖动角色后自动关闭并保留落点，重新开启恢复移动。支持鼠标、触屏和角色聚焦后的方向键；拖动不会触发重听。角色避开底部设施栏，弹窗打开时隐藏。轻点场景中的角色可以重听或打断讲解。

手动选择「行走／小跑」会实际水平移动并在边缘往返，不依赖「自动游走」开关；拖动会恢复自然动作、保留落点，重新选择行走可继续。步态只在实际发生位移时播放，隐藏与减少动态状态会暂停移动。角色是屏幕桌宠叠层，不按园区真实比例尺缩放：高度约为视口的 22%，最高 210px，可用地图空间受限时进一步缩小。「关切」改为柔和浅笑、轻抬眉和微侧头，保留各动物自身嘴形，避免嘴角向下的苦脸。

行走双腿不再横向摆转：SVG 固定左右足道交替缩短提足；3D 使用髋、膝、踝的双段 IK，保持膝盖弯曲方向和脚底水平。常规行走侧转约 32°，减少侧视脚掌相互遮挡；独立转向动作仍保留。回归测试采样实际关节与网格，检查完整步态周期中的足道、膝踝顺序及腿段投影。

此前的程序化版本虽增加毛发／卷丝、衣饰接缝和配件细节，仍不能完整复制原图的水彩和毛毡质感；新增原画版本因此直接保留参考图像素。动物形象的资产制作方案、成本与验证建议见 [ANIMAL_AVATAR_RESEARCH.md](ANIMAL_AVATAR_RESEARCH.md)。

原创 2D 使用 SVG 关节层级；官方 2D 使用本地 Live2D Cubism Web runtime 和 Wanko 模型。3D 使用本地 Three.js 0.170.0（MIT，许可见 `src/vendor/THREE-LICENSE.txt`），官方版本加载 Fox glTF 模型。Live2D、Cubism Core、Wanko 和 Fox 的许可及来源分别见 `public/assets/avatars/live2d/ATTRIBUTION.md`、`public/assets/avatars/live2d/LICENSE.md` 和 `public/assets/avatars/3d/ATTRIBUTION.md`。渲染均在本机计算，不需要数字人推理服务器；这仍会占用浏览器 CPU/GPU，也不代表语音识别或合成完全离线。

交互模式进入页面或切回语音时默认准备麦克风。真实采音开始后显示动态波形与「正在聆听 · 点击暂停」；讲解时显示「点击打断」。手动暂停后保留暂停状态，使用麦克风图标恢复。权限、设备和连接问题展示具体提示，不会伪装为正在采音。首页固定使用立体地图，不再提供俯视切换按钮。

未获授权时，点击话筒会通过 `getUserMedia` 请求真实麦克风权限，检查成功后释放临时采集流，再启动语音链路。授权成功本身不会显示「正在聆听」，需等真实采音启动。错误状态下可打开「权限帮助」查看安全上下文、浏览器接口、页面策略和最近权限结果。网页无法解除浏览器保存的拒绝：需在地址栏站点权限和系统隐私设置中允许麦克风。若内嵌浏览器禁止采集，可复制弹窗中的当前地址到 Chrome 或 Edge 打开；在运行服务的电脑上使用 `http://localhost:5174/` 或 `http://127.0.0.1:5174/`。

轨迹和避让属于独立的应用逻辑，目前采用边缘停靠、限速移动与设施栏避让，没有实现任意障碍物全局寻路；后续可替换为网格 A*、导航网格或基于设施矩形的局部避障。

浏览器验证脚本 `scripts/verify-companion.mjs` 需要 Playwright，可通过 `PLAYWRIGHT_MODULE` 指定其模块路径、`CHROME_PATH` 指定 Chrome、`DEMO_URL` 指定地址。覆盖 320 / 390 / 1440px 及 844×390 横屏，检查导游切换、Canvas 尺寸、动画、菜单边界与点击命中、键盘关闭、紧凑布局、设施栏避让及窗口缩放恢复；截图保存到 `artifacts/companion/`。

需要 Node.js 24 及以上（使用原生 TypeScript 类型擦除运行后端，`npm run typecheck` 独立做严格类型检查）。默认端口为 **5174**，也可通过 `PORT` 修改：

```bash
npm install
npm run dev:lan
```

打开终端打印的本机或 Wi-Fi 地址；手机与电脑连接同一热点。HTTP 局域网地址可测试地图、照片、文本操作；手机麦克风需要受信任的 HTTPS 和支持语音识别的浏览器。项目支持通过 `TLS_CERT_PATH` / `TLS_KEY_PATH` 配置现有证书（见 `.env.example`）。不能用只在电脑有效的 localhost 地址测试手机。

不需要安装额外 IDE。项目文件可在 Codex 客户端打开，直接提出修改要求即可。

## 体验路径

1. 先试“卫生间在哪”“找出口”“服务中心在哪里”，对应地标会在地图内高亮、放大，并显示简短气泡，不再弹出下方设施面板。无坐标服务信息贴在“服务”按钮旁。点“风景”继续探索；“全园”恢复完整边界。
2. 首页选择“建筑故事”，地图突出推荐点；点“带我看看”或说“好的”进入对应园区照片。
3. 画面真正加载成功后才开始讲解。当前导游的嘴部状态由 TTS 实际播放事件驱动，字幕和画面提示跟随句子边界；文字介绍进入同一对话，不再打开额外介绍页。
4. 重复进入同一景点不会自动重播。点导游或说“继续讲解”可重听；说“介绍铁塔”也可明确请求重讲。
5. “探索景点”按名字、别名或区域检索；无照片的点显示资料和资源缺口。
6. 页面会尝试默认准备聆听；浏览器可能要求一次麦克风授权。实际采音时按钮显示动态波形，提示点击暂停；讲解时可点击打断并继续聆听。切后台、权限或网络错误会暂停，官方 Fox 没有口型同步。
7. 主动欢迎与下一站提示默认只展示文字，每种提示每次页面会话最多一次，至少间隔 60 秒；忙碌、输入、后台、详情或弹层打开时不主动打断。拒绝或停止后不再主动提示。

地图与景点操作使用前端本地指令；开放问题由本项目 Fastify 后端调用模型并执行本地工具。未配置文字密钥时使用明确标注的规则演示。服务异常会显示提示，仍可继续使用本地指令。

## Fastify + TypeScript 后端（2026-11-13）

已将 `VirtourV2/server` 的文字模型调用、Qwen 原生语音、七个工具及世界之窗知识快照迁入 `server/ai/`，不再通过旧导览应用转发。前端代码和三个现有接口协议保持兼容。

- `POST /api/guide`：本地执行规则演示或文字模型工具循环，返回完整 JSON 回答；保留最近至多 10 条对话和有来源的景点上下文，不上传游客定位。整轮 60 秒超时。
- `POST /api/voice`：浏览器录音后提交 Base64 PCM；本服务端直接建立 Qwen WebSocket、执行工具，向浏览器流式返回原有 NDJSON 语音、字幕与答案事件。输入 16kHz、16bit 单声道，输出 24kHz PCM，整轮 120 秒超时。
- `GET /api/status`：报告本服务的演示／真实模型配置与语音是否已配置，不返回密钥和模型端点。`providerStatus: configuration-only` 表示尚未验证供应商网络、余额和模型权限，不是在线可用性保证。
- `GET /api/health`、`GET /api/tools`：进程健康与七项工具目录。
- 文字和语音共享 3 个并发名额；有输入校验、请求大小限制、跨站请求拒绝、取消传播与语音积压上限。

### 服务端配置

复制根目录 `.env.example` 为 `.env`，按需配置：

- **真实文字问答**：`DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`。支持经验证的 OpenAI-compatible Chat Completions 端点。
- **原生语音**：`DASHSCOPE_API_KEY`、`QWEN_REALTIME_URL`、`QWEN_AUDIO_MODEL`、`QWEN_VOICE`。密钥、业务空间、地域、模型和音色需匹配；语音不需要文字模型密钥。
- 没有文字密钥时仍可检索本地知识库，回答明确标记“离线规则演示”；没有语音密钥时返回未配置错误，不伪装为语音已启用。
- 配置只由服务端环境加载，没有匿名修改密钥的接口，也没有移入其他项目的 `.env` 或密钥。修改后重启服务。

前端录音、播放、暂停与打断行为不变；手机麦克风仍需受信任 HTTPS。固定文本讲解仍使用浏览器合成，当前没有独立 `/api/tts`。知识库为带来源限制的关键词检索快照，不是向量数据库；天气、其他城市景点和预算工具保留“示例／模拟”标记。

`npm run preview` 同样运行 Fastify 并提供这些 API。纯静态发布和 `file://` 预览无法运行后端模型能力。当前仍为可信单用户演示，没有用户鉴权、持久化会话或完整公网限流；不要直接无保护地暴露公网。迁移边界、验证与启动说明见 [docs/BACKEND_MIGRATION.md](docs/BACKEND_MIGRATION.md)。

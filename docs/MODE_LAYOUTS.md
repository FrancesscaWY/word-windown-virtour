# 主页面三种模式（2026-11-11）

项目主要页面为欢迎页、模式引导页、地图首页和景点画面页。景点文字介绍不再作为独立页或浮层出现：没有画面资源的景点保持地图，通过当前对话或语音介绍；查看故事也进入同一对话。已有实拍素材继续按真实资源展示，不伪称为 360° 全景，作者与许可链接显示在照片下方。

## 布局

- 交互语音：大画面与紧凑状态栏。导游姓名下只留一句当前状态，不重复显示播放标签、字幕和长欢迎文案。麦克风错误仍有简短状态及帮助图标，完整恢复说明放在帮助弹窗。
- 交互文字与沉浸模式：默认画面 40%、对话 60%；手机上下排列，宽屏与短横屏左右排列。拖动两区之间的细柄调整比例；方向键调整、Home / End 到边界、Enter 或双击还原。窄小视口为输入和聊天保留最小空间。模式切换保留当前调整，刷新恢复默认比例。
- 对话区只留角色姓名和一句模式提示。头像去掉边框，消息使用接近全宽的气泡，游客消息靠右；实际景点推荐才显示简短推荐入口，可以取消。
- 伴游模式保留地图、定位轨迹和语音操作，显示可拖动数字形象，也可切换角色、表情及动作。两套原画版本“沐沐 · 水彩”“绒绒 · 毛毡”位于列表前两位，其他角色保留。
- 欢迎页入口改为轻量文字和无圆框的左向箭头，保留点击及左滑进入引导页。模式菜单只列三个模式，去掉“重新选择游览模式”入口提示。

## 播放与定位

伴游切后台时停止识别和待重启的收音，但不调用停止讲解，当前音频继续。返回前台后等待当前讲解结束，再恢复聆听。暂停伴游、切换模式和离开页面仍停止相关会话；定位默认使用本地模拟路线，自动推进；暂停伴游同时暂停路线，恢复时从原位置继续。首页移除定位来源下拉及设置图标，不请求手机定位。浏览器或操作系统对后台音频、页面冻结的限制仍然适用。

地图轨迹最多保留 600 个点，仅存在当前访问内存中。位置跳变分段；离开伴游模式清除轨迹，重新进入从模拟路线起点开始。真实语音状态由浏览器事件驱动，授权成功本身不会显示正在聆听。

## 验证

- `npm test` 包括新分栏边界、取消独立介绍页，以及伴游后台保留讲解/前台恢复识别的回归测试。
- `node scripts/verify-modes.mjs` 检查 320×740、390×844、844×390、1440×900 的实际布局、默认 4:6 比例、拖动后实际尺寸变化、键盘还原、推荐跳转和取消、角色顺序与伴游显示。模拟语音接口、验证无需 GPS 的本地模拟定位，并通过实际页面的 visibilitychange 处理器检查后台逻辑；不代表实机系统后台音频或真实语音服务已验证。
- `node scripts/verify-arrival.mjs` 检查欢迎页与引导页六种尺寸、点击与历史往返、三个模式及全景往返。
- `npm run check` / `npm run build` 验证模块、静态站与自包含离线预览。截图在 `artifacts/modes/` 和 `artifacts/arrival/`。

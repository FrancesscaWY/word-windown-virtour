# 欢迎页与模式引导页

本次只新增入口页面和独立素材，未修改 `src/main.js`、`public/styles.css`、数字导游、语音服务或现有全景组件。

## 四个主要页面

1. `/` 或 `/index.html`：欢迎页，使用用户附件中的竖排标题、水彩世界建筑、动物导游和左滑提示。支持点击和横向左滑进入引导页。
2. `/modes.html`：模式引导页，按 `yindao.png` 还原纸张、水彩、枝叶、卡片和中文文案；三个卡片分别进入现有交互、沉浸和伴游模式。可返回欢迎页。
3. `/tour.html?mode=interactive`（也支持 `immersive`、`companion`）：现有主页面，导游、表情、动作、拖动、地图与语音功能保留。
4. 全景副页面：沿用现有主页面的地标入口，点击铁塔进入原有全景，再使用“地图”返回。照片和无全景资料的处理保留。

模式卡片通过独立的 `src/tour-entry.js` 复用现有模式控制器，确保伴游模拟器和语音生命周期继续由原代码管理；没有在欢迎页或引导页申请麦克风、定位权限。主页面模式菜单仅保留三种模式切换，已取消“重新选择游览模式”提示。浏览器返回使用普通页面历史，不劫持已有前进/后退操作。

附件中的“窗小游”用于新增入口插画和文案。现有主页面中的数字导游没有被替换或改名，其他任务正在增加的形象也不受限制。伴游页仍保留原有模拟定位/设备定位机制，没有新增后台定位能力。

## 构建与独立检查

- `npm run dev`：本地入口仍使用原服务地址，服务启动方式不变。
- `npm run build`：输出欢迎页、引导页和主页面的静态站。原 `dist/offline-preview.html` 继续作为自包含的导游/全景预览，避免破坏现有离线检查流程。
- `npm run deploy:package`：一并打包三个 HTML 入口和派生素材，不发布任何外部站点。
- `node scripts/verify-arrival.mjs`：需要可用的 Playwright 和 Chrome；可通过 `DEMO_URL`、`PLAYWRIGHT_MODULE`、`CHROME_PATH` 指定地址与运行环境。专门检查两张新增页面、三个模式衔接和全景往返。
- 既有地图与角色浏览器检查默认直接访问 `/tour.html`，可独立于新增欢迎流程继续运行。

所有设计素材均保留原始附件；裁切/缩放步骤与摘要见 `public/assets/arrival/README.md`。

## 入口动效与界面层次

欢迎页按晕染展开、竖排标题揭示、建筑浮现、窗小游弹跳迎接、旅程路径描绘、入口按钮出现的节奏入场。保留附件的全部五组素材，建筑去除纸张矩形底色并羽化边缘；人物、建筑和地面光晕组成同一场景。点击窗小游可触发轻跳、星光和欢迎语。平时只有小幅呼吸、纸飞机浮动与按钮引导，未引入 WebGL、动画库或在线服务。

模式引导页使用实体奶油色卡面、双层底沿、环境投影、内边高光和独立插画层，三卡错开入场。桌面鼠标可触发最大 2.5 度的卡片倾斜与跟随光影；触屏保留按压反馈。倾斜更新最多每帧一次，离开卡片和页面时清理。

两张入口页均占满当前动态视口，不设超过屏幕的最小高度。引导页按导航、标题、卡片、页脚四行分配空间，三张卡片在手机上均分剩余高度，桌面横向并列；矮屏手机改用插画与文案左右布局，保持三个模式与底部提示同屏可见。枝叶素材已去除原纸张底色，避免左上出现矩形色块。

欢迎页将原图片的“世界之旅”和“AI 伴游”分成独立图层，将伴游一列上移、缩小并收在主标题高度内。标题按场景可用高度缩放，降低建筑占比，调整角色、问候语、入口按钮之间的留白；矮屏横向布局也不再使用 430px 的固定最小高度。保留标题、人物、建筑与动效；入口按钮采用轻量正文与无外框箭头。

点击入口、模式或返回链接时增加 260ms 退场过渡；点击和左滑共用导航锁，防止连续触发。保留原生链接、修饰键打开新标签、下载和浏览器历史行为；恢复缓存页面时清除退场状态。入口动画用 CSS 实现，脚本失效仍可观看页面并使用链接。系统启用“减少动态效果”时禁用动画、倾斜与导航等待。

相关逻辑位于独立的 `src/arrival/presentation.js`、`src/welcome-page.js` 与 `src/modes-page.js`，不依赖原有地图、数字导游或语音模块。

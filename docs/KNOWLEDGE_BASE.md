# 世界之窗文档知识库

## 已接入的范围

用户提供的 `agent-tmp/1.docx` 已离线转换为 110 个知识条目，覆盖园区与建园历史、18 个景点的原景／园内仿建／摄影、8 个故事、服务设施、交通和 R01—R05 五条编辑路线。资料口径截至 **2026-11-12**，不是实时运营数据；导入不代表核验了文档或附录网页。

- `server/ai/knowledge/window-of-world.source.json`：按正文顺序保存的语义原文快照，保留 25 张表的表头与 242 行数据、原 DOCX 文件名和 SHA-256。用于追踪与重建；不依赖被忽略的 `agent-tmp/`，不是可还原 Word 排版的备份。
- `server/ai/knowledge/window-of-world.json`：运行时读取的结构化知识库，包含 110 个条目、本地文档来源和 22 个附录来源。每个条目包含主题、实体、关键词、原章节、资料日期、来源 ID 与引用 ID。
- `server/ai/knowledge-import.ts`：TypeScript 离线解析、表头保留、分块和本篇文档的显式映射规则。
- `server/ai/knowledge-schema.ts`：生成时和启动时共用的 Zod 校验，拒绝重复 ID、未知来源与非 HTTPS 外部来源链接。
- `server/ai/knowledge.ts`：实体／别名加主题的本地关键词排名。没有 embedding、向量数据库、在线抓取或重排服务。

## 重复生成

Node.js 24+；执行前安装项目锁定的依赖。运行时不需要 OfficeCLI、Python、模型或 API Key。

```bash
npm run knowledge:import -- agent-tmp/1.docx
```

原 DOCX 不在时，可以从跟踪的语义原文快照重建：

```bash
npm run knowledge:import -- server/ai/knowledge/window-of-world.source.json
```

两种输入写入相同的上述 `.source.json` 和运行时 `.json`；解析和校验全部成功后才开始写入文件。输出不包含当前生成时间，便于稳定 diff。**当前导入规则专门适配已审阅的这份世界之窗文档，不是任意 Word 文档导入器。** 文档章节、表格、来源数量或资料日期变化时，需要先审阅并修改导入 profile；不能用该命令直接给另一份文档套上当前日期和来源。

知识库在后端启动时加载；修改或重新导入后需重启已有服务进程。无需修改模型密钥、前端 API 协议或配置数据库。

## 检索与工具

- `search_knowledge_base`：查询保留景点名和完整主题。景点别名与英文名归一化；实体问题不串到其他景点。J 出口与路线编号有专用检索优先级。
- `get_attraction_details`／`get_attraction_story`：已收录的景点读取文档片段及其引用；其他原目录景点仍返回原摘要，未收录不补写。
- `search_attractions`：增加文档别名及目录缺少的景点；不生成坐标，不提升原目录的位置核验等级。
- `plan_itinerary`：可按亲子等兴趣返回编辑路线资料，但 `route` 和 `ticket_total` 仍为 `null`，不冒充导航或确定预算。
- 文字和 Qwen 原生语音共用这套工具。无密钥仍按原协议返回未配置错误，不提供演示回答。

## 来源与安全边界

1. 文档来源的 `url` 为 `null`，不能编造下载链接或向游客暴露本地绝对路径。文字使用 `[WOW:条目id]`，有相关附录链接可附上；语音自然说明来源与限制。
2. 附录来源按章节用途进行关联，**不是逐句背书**。没有实际网页采集日期、发布日期的字段保持 `null`，不伪造已访问或已核实状态。
3. `dynamic` 条目的 `current_status` 固定为 `not_verified`，并保留资料日期。票价、营业时间、夜场、设施与地铁出口不能当成今天或未来出游日有效；预算工具依旧不合计未知价格。
4. 原景的建造年代不等于深圳复制景观的建造年代；宗教传说、碑文梦境不是已证实的超自然史实；摄影、路线、停留时长为编辑建议。R01 原文 350／355 分钟差异已显式注明，不伪装精确计时。
5. 导入只读取指定本地文件，不下载 URL、不执行宏／嵌入内容；拒绝 DTD、实体声明、畸形 XML 和不符合 profile 的文档。输入上限 10 MiB、ZIP 总展开上限 32 MiB、正文 XML 上限 8 MiB、ZIP 条目上限 1000。没有新增匿名上传或写知识库接口。
6. 检索资料不能覆盖系统指令。这是小规模关键词基线，不保证任意中文同义表达都能召回；资料未命中不代表园区没有该景点或服务。
7. 本次未改前端地图、坐标、固定开场讲解或自动路线执行。数据库、通用文件上传、在线更新、向量检索和地图导航不在接入范围内。
